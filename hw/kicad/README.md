# Проект KiCad: несущая плата FPGA-синтезатора АВК-6

Схема по описанию [`../schematic.md`](../schematic.md) и требованиям
[`hw-requirements.md`](../../.plans/fpga-synth/hw-requirements.md). Формат — **KiCad 7** (открывается и в 8/9,
при сохранении KiCad обновит формат). PDF всех листов — [`avk_synth.pdf`](avk_synth.pdf).

| Файл | Что |
|---|---|
| `avk_synth.kicad_pro`, `avk_synth.kicad_sch` | проект и корневой лист |
| `power`, `fpga`, `midi_sync`, `ain1`, `ain2`, `adc`, `dac`, `aout`, `hp`, `panel` `.kicad_sch` | листы (как в `schematic.md`, раздел 0) |
| `avk_synth.kicad_sym`, `sym-lib-table` | свои символы: **AD7091R**, **Tang_Nano_20K** (в стандартных библиотеках KiCad 7 их нет) |
| `tools/gen_kicad.py` | генератор: все детали, номиналы, посадочные места и цепи — в нём |
| `tools/check.py` | проверка: KiCad экспортирует netlist, он сравнивается с задуманными цепями |
| `tools/render.sh` | экспорт листов в SVG/PNG для просмотра |

## Как устроена схема

- Символы и посадочные места — **из стандартных библиотек KiCad** (Device, Diode, Audio, Amplifier_Audio, Comparator,
  Analog_ADC, Isolator, Regulator_Linear, Reference_Voltage, Memory_Flash …). Где точного символа нет, взят
  совместимый по выводам: OPA2350 — символ TLV9062, OPA2171 — символ OPA2277, W25Q64JV — символ W25Q32JVSS.
- Детали **сгруппированы по узлам** (подписи групп — на листе), выводы соединены **метками цепей**: локальные —
  внутри листа, глобальные — между листами, земля — символом GND. Проводов между деталями нет: это схема
  «на метках», её удобно читать по цепям и сверять с `schematic.md`; при желании перерисовать проводами в KiCad.
- Имена цепей к ПЛИС совпадают с портами `fpga/boards/tang_nano_20k/top_synth.sv`.
- Обозначения — как в `schematic.md` (R101…, U401…), аннотация не нужна.

## Проверено

- `python3 tools/check.py`: все **153 цепи** netlist KiCad совпадают с задуманными, нет повторов обозначений
  и цепей из одного вывода.
- Цоколёвки PCM5102A, LM339, MCP3208, H11L1, BAT54S, 74LVC1G17, W25Q, TPA6132A2 взяты из символов KiCad
  и сверены с `schematic.md`.
- ERC в KiCad 7 из командной строки недоступен — **запусти ERC в редакторе** при первом открытии.

## Не проверено — сверить до разводки

| Что | Где |
|---|---|
| Номера выводов **AD7091R** (свой символ, по памяти) и режим внешней опоры | `adc`, HO-09 |
| Выводы **Tang Nano 20K**: имена с `[IOnn]` — из `.cst` (предварительно), остальные не назначены; посадочного места нет | `fpga`, HO-01 |
| Распиновка **нижнего разъёма** J101 (сейчас Conn_01x05) и его посадочное место | `power`, HO-06 |
| TPA6132A2: HPVDD (конденсатор или к VDD), G0/G1 для 0 дБ, EN | `hp` |
| Порядок выводов модуля дисплея J901 и тип входа BLK | `panel` |
| Посадочные места панельных деталей (гнёзда TRS, потенциометры, энкодеры) — по купленным деталям | все |

## Перегенерация

```bash
python3 hw/kicad/tools/gen_kicad.py     # перезаписывает *.kicad_sch и avk_synth.kicad_sym
python3 hw/kicad/tools/check.py         # нужен kicad-cli (sudo apt install kicad)
```

**Генератор перезаписывает листы.** Пока схема правится через `gen_kicad.py` — правь его и `schematic.md` вместе.
Как только начнёшь править схему руками в KiCad (перерисовка проводами, разводка), генератор больше не запускай:
источником правды становятся файлы KiCad, а `check.py` можно оставить для сверки цепей с `schematic.md`.
