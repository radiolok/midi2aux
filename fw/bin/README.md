# Готовые прошивки (ATmega328P, 16 МГц)

| Файл | Что это | Сборка |
|---|---|---|
| `midi2aux_mono.hex` | Исходная одноголосная прошивка. Побайтно совпадает с hex, собранным из исходников master (eefc972). | `cmake --build build`, цель `midi2aux` |
| `midi2aux_mono_env.hex` | Моно + огибающая синуса на потенциометре (`SINE_ENV`). Остальные формы — как в исходной прошивке. | цель `midi2aux_env` |
| `midi2aux_poly4.hex` | Прототип полифонии: 4 голоса, fs 31,25 кГц, аккумулятор 24 бит, ШИМ 62,5 кГц / 8 бит (TOP = 255), огибающая синуса включена. | цель `midi2aux_poly`, параметры по умолчанию |

Собрано avr-gcc 5.4.0, `-Os`. Подробности о поли-режиме — в `docs/polyphony.md`.

## Прошивка

Перед прошивкой снимите перемычку MIDI: оптрон на PD2 отключает RX.

```bash
# Nano со старым загрузчиком (57600); с новым (Optiboot) замените на -b 115200
avrdude -p atmega328p -c arduino -P /dev/ttyUSB0 -b 57600 -U flash:w:midi2aux_poly4.hex:i
avrdude -p atmega328p -c arduino -P /dev/ttyUSB0 -b 57600 -U flash:w:midi2aux_mono.hex:i
avrdude -p atmega328p -c arduino -P /dev/ttyUSB0 -b 57600 -U flash:w:midi2aux_mono_env.hex:i
```

## Что проверить на огибающей (`mono_env`, `poly4`, режим синуса)

- Ручка влево: короткий «щипок» (~50 мс). Ближе к середине — затухание растёт до ~3 с,
  даже если клавиша зажата. Отпускание клавиши глушит звук за 80 мс.
- Ручка правее середины: орган (звук держится, пока зажата клавиша). Вправо до упора —
  пэд: атака ~1 с, затухание после отпускания ~2 с.
- Нет щелчка в конце затухания: в режиме синуса молчащий выход стоит в середине шкалы.
- На моно-прошивке хвост затухания может звучать «зернисто»: у синуса там ±49 уровней ШИМ.

## Что проверить на поли-прошивке

- Аккорд из 2–4 нот: каждая звучит, отпускание одной клавиши гасит только её.
- Пятая нота забирает самую старую.
- Кнопка переключает форму (меандр / треугольник / синус) и глушит все голоса.
- Потенциометр меняет скважность меандра и излом треугольника.
- Несущая ШИМ теперь 62,5 кГц вместо 160 кГц: посмотрите пульсации после RC-фильтра.
- Одна нота звучит тише, чем в моно (1/4 шкалы, −12 дБ): так и задумано.
