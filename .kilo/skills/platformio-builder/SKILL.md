# Инструкция по работе с PlatformIO

Ты — AI-агент, специализирующийся на автоматизации сборки и загрузки прошивок для PlatformIO.

## Доступные задачи

1.  **Полная сборка и загрузка (Build & Upload)**:
    *   Эта команда выполняет компиляцию всего проекта и сразу прошивает устройство.

2.  **Только сборка (Build only)**:
    *   Эта команда только компилирует проект, не пытаясь прошить устройство. Используется для быстрой проверки кода.

3.  **Только загрузка (Upload only)**:
    *   Эта команда загружает на устройство последнюю успешно собранную версию прошивки.

4.  **Монитор**:
    * Эта команда открывает терминал и читает все что пишет устройство в последовательный порт

## Правила выполнения

1.  **Определение окружения**:
    *   Перед запуском команд всегда проверяй, что находишься в корневой директории проекта, где лежит файл `platformio.ini`.
    *   Если в проекте несколько окружений (environments), уточни у пользователя, какое именно нужно использовать. По умолчанию используй стандартный `pio run` без указания флага `-e`.

2.  **Выполнение команд**:
    *   Для выполнения задач используй следующие точные команды:

        **Команда 1 (Полная сборка и загрузка):**
        ```bash
        pio run --target upload
        ```

        **Команда 2 (только сборка):**
        ```bash
        pio run
        ```

        **Команда 3 (Только загрузка последней версии):**

        ```bash
        pio run --target upload --upload-no-build
        ```
        Если нужно указать конкретное окружение (например, env:esp32dev), используй флаг -e:

        ```bash
        pio run -e esp32dev --target upload
        ```

        **Команда 4 (Монитор)**
        ```bash
        pio device monitor
        ```

3. Обработка ошибок:

      Если сборка завершилась с ошибкой, внимательно проанализируй вывод терминала и предложи пользователю варианты исправления.

      Наиболее частые ошибки — отсутствие подключенной платы или неверно указанный порт. В случае ошибки загрузки посоветуй проверить подключение.
