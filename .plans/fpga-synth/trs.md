# ТЗ: FPGA-синтезатор / процессор эффектов — сменный модуль АВК-6

Статус: **черновик v0.2**. Приоритеты: **P0** — обязательно в первой версии, **P1** — во второй, **P2** — потом.
Открытые вопросы собраны в разделе 10 (`O-xx`).

---

## 1. Назначение

Сменный модуль АВК-6, развитие проекта MIDI2AUX:

1. **Полифонический виртуально-аналоговый синтезатор** с MIDI-входом, реакцией на силу нажатия и огибающими.
2. **Процессор сигналов АВК**: два DC-входа, эффекты на кольцевом буфере (задержка, хорус, реверберация) и математические операции над сигналами.
3. **Связь синтезатора с АВК в обе стороны**: сигналы АВК модулируют синтезатор, а модуляционные сигналы синтезатора выводятся в АВК.

## 2. Термины

| Термин | Значение |
|---|---|
| Машинная единица (МЕ) | ±10 В на разъёмах АВК. В цифре соответствует ±1.0 |
| Полная шкала (FS) | ±12.5 В на входах/выходах модуля (запас 25 % над МЕ), см. `hw-requirements.md` Т-1.2 |
| Голос | Канал синтеза одной ноты: 2 генератора + шум → фильтр → усилитель с огибающей |
| ADSR | Генератор огибающей: Attack (время нарастания), Decay (время спада), Sustain (уровень удержания), Release (время затухания после отпускания) |
| LFO | Низкочастотный генератор модуляции, 0.01–50 Гц |
| Velocity | Сила нажатия клавиши, 0–127, приходит в Note On |
| Шина сигналов | Набор сигналов модуля (источники, выходы слотов), обновляется каждый отсчёт |
| Слот | Аппаратный блок обработки (эффект / математика) со стандартным интерфейсом, подключённый к шине |

## 3. Внешние интерфейсы

### 3.1 Питание (от АВК)

| Шина | Потребители | Примечание |
|---|---|---|
| +5 В | Tang Nano (вход 5 В через диод Шоттки — развязка с USB), MCP3208, логика | Ток ограничен, величина неизвестна (O-11); бюджет ≤ 400 мА |
| +15 / −15 В | ОУ входных/выходных каскадов, компараторы светодиодов | |
| 3.3 В | АЦП входов, ЦАП, дисплей | Отдельный LDO от +5 В (не от Tang Nano) |

Земля АВК одна: одна земля на плате, развязка керамикой и электролитами у каждого узла, аналоговая часть топологически отделена от цифровой.

### 3.4 Конструктив

- Алюминиевая панель 120×90 мм, плата под ней на стойках по углам, модуль вставляется в АВК сверху.
- Снизу — разъём модуля: питание +5 / ±15 В, земля, СИНХР.
- Tang Nano 20K устанавливается на несущую плату на штыревых разъёмах (можно снять).
- Прошивка и отладка — через ремонтную проставку: модуль поднимается над корпусом, открывается доступ к USB-C Tang Nano.
- SD-карта — в слоте Tang Nano (доступ при вынутом модуле).

### 4.3 Модуляция (связь с АВК) — ключевая функция

**Матрица модуляции**: 8 маршрутов «источник → приёмник × глубина (±)», глобальные (действуют на все голоса).

| Источники | Приёмники |
|---|---|
| ВХ1, ВХ2 (DC, с частотой отсчётов — годится и для FM/AM звуковой частоты) | Высота тона всех голосов (FM / экспоненциально по октавам) |
| LFO1, LFO2 | Частота среза, резонанс |
| Mod Wheel, Pitch Bend | Громкость (AM / кольцевая модуляция) |
| Выходы слотов | Ширина импульса (PWM), смесь генераторов |
| СИНХР (±1) | Частота LFO, параметры слотов (время задержки, обратная связь…) |

Pri: ВХ1/ВХ2 → высота, срез, громкость — **P0**; остальное — P1.

**Модуляция АВК от синтезатора** — на ВЫХ2 (правый канал ЦАП) выводится любой сигнал шины:

| Сигнал | Описание | Pri |
|---|---|---|
| LFO1/LFO2 | ±10 В | P0 |
| Огибающая последнего нажатого голоса | 0…+10 В | P0 |
| Gate | 0 / +10 В, пока нажата хотя бы одна клавиша | P0 |
| Pitch CV последней ноты | 1 В/окт или в МЕ (настраивается) | P1 |
| Velocity последней ноты | 0…+10 В | P1 |
| Огибающая сигнала (envelope follower) синта или ВХ | 0…+10 В | P1 |

### 4.4 Вход СИНХР

| Режим | Pri |
|---|---|
| Такт для эффектов и LFO: время задержки / частота LFO = период СИНХР × множитель (4, 2, 1, 1/2, 1/4, 1/3…) | P0 |
| Триггер нот: фронт запускает огибающие (выбранная нота или последняя нажатая); длительность gate — параметр | P0 |
| Измерение периода (служебно: показать частоту на экране; основа для тактовых режимов) | P0 |
| Жёсткая синхронизация генераторов | P1 |
| Слежение частоты (голос звучит на частоте генератора АВК × интервал) | P2 |
| Выборка-хранение по СИНХР | не нужно (сигналы АВК синхронны с СИНХР) |

## 5. Функциональные требования — обработка сигналов

### 5.1 Шина сигналов и слоты

- Шина: `NUM_BUS` сигналов по 18 бит, обновляется каждый отсчёт.
  Источники: S0 синт (сумма голосов), S1 ВХ1, S2 ВХ2, S3 LFO1, S4 LFO2, S5 СИНХР, S6 огибающая, S7 gate, S8… выходы слотов.
- Каждый слот выбирает входы `SEL_A`, `SEL_B` из любых сигналов шины. Слоты вычисляются по порядку; чтение выхода более позднего слота даёт значение предыдущего отсчёта (z⁻¹) → допустимы обратные связи.
- Выходной микшер: `ВЫХ = softclip(Σ gain_i · S_i)`, `ВЫХ2 = S[sel_out2] · gain`.
- **Расширяемость**: новый эффект = RTL-модуль со стандартным интерфейсом слота + строка в списке слотов верхнего уровня + дескриптор в прошивке. Остальной код не меняется. CPU при старте перечисляет слоты по `TYPE_ID`, меню строится из дескрипторов.

### 5.2 Набор слотов

| Слот | Описание | Память | Pri |
|---|---|---|---|
| MATH | A·B (как у АВК: Y = A·B·0.1 в вольтах), A/B (с насыщением), \|A\|, A+B, A−B, min, max, A mod B, A·k+B | — | P0 |
| DELAY | Задержка сигнала (в т.ч. «замедлить» = задержать вход АВК) до нескольких секунд, обратная связь, dry/wet, время от энкодера или от СИНХР | SDRAM / PSRAM | P0 (на 20K) |
| CHORUS / FLANGER | Короткая задержка, модулированная LFO | BSRAM | P1 |
| REVERB | Freeverb или Dattorro (набор гребёнчатых и all-pass фильтров) | BSRAM / SDRAM | P1 |

Конфигурация по умолчанию для первой версии: 2× MATH, 2× DELAY, 1× CHORUS, 1× REVERB (параметр).

## 6. Нефункциональные требования

| Параметр | Значение |
|---|---|
| Частота отсчётов | ≈ 48 кГц. Точное значение — из PLL от кварца 27 МГц, отклонение ≤ 3 % допустимо; таблица нот считается от фактической fs. Сейчас: sys_clk 99 МГц, BCK = sys_clk / 32, fs = 48 339.84 Гц (+0.7 %) |
| Разрядность внутреннего тракта | 18 бит (под умножители 18×18), параметр `DATA_W` |
| Формат отсчётов | Q2.16: 1.0 = 2^16 = МЕ (±10 В), внутри тракта запас до ±2 МЕ; на выходе ×1.6 → МЕ = 0.8 FS ЦАП |
| Высота тона | лог-шкала `log2(inc) · 2^16`, 21 бит; модуляции высоты складываются в ней |
| Разрядность входных АЦП | 12 бит (параметр `ADC_W`) |
| ЦАП | I2S, кадр 32 бита, данные 18 бит, младшие биты = 0 |
| Задержка MIDI → звук | ≤ 3 мс (без учёта передачи MIDI-сообщения ~1 мс) |
| Задержка ВХ → ВЫХ (без эффектов) | ≤ 1 мс |
| Опрос потенциометров | ≥ 100 Гц на канал, сглаживание, гистерезис |
| Сумматор голосов | запас разрядности на 32 голоса + мягкий лимитер, без цифрового переполнения |
| Параметризация RTL | `NUM_VOICES`, `NUM_SLOTS`, состав слотов, `DATA_W`, `ADC_W`, целевая плата (9K/20K) |

### 8.1 Разделение RTL / CPU

| RTL | CPU (C) |
|---|---|
| Весь звуковой тракт, эффекты, АЦП/ЦАП | Распределение голосов, кража, sustain |
| UART MIDI + парсер → FIFO событий | Нота → инкремент фазы, pitch bend, mod wheel |
| Декодеры энкодеров, SPI-контроллеры | Меню, дисплей, пресеты (SD) |
| Измерение периода СИНХР, триггер | Перевод значений ручек в параметры (кривые, сглаживание) |

### 8.2 Карта памяти (предварительно)

| Адрес | Назначение |
|---|---|
| `0x0000_0000` | BSRAM: код + данные |
| `0x0010_0000` | Boot ROM (загрузчик, 4 КБ, вектор сброса) |
| `0x1000_0000` | Периферия, блоки по `0x100`: 0 UART, 1 таймер, 2 GPIO, 3 FIFO MIDI, 4 sysinfo, 5 SPI-флеш, 6 ручки (MCP3208), 7 энкодеры, 8 дисплей, 9 СИНХР, 10 АЦП ВХ1/ВХ2, 11 SPI SD-карты (`sw/include/hw.h`); sysinfo `+0x28` MEM_WORDS, `+0x2C` NUM_SLOTS |
| `0x2000_0000` | Голоса: голос k по `+k·0x40` (PITCH1, PITCH2, GATE, VEL_AMP, CUT_OFS, STATUS) — см. `voice_engine.sv` |
| `0x2001_0000` | Глобальные параметры синта (формы, смесь, фильтр, ADSR1/2, PM/CM/AM) |
| `0x2002_0000` | Блок модуляции: LFO1/2, матрица из 8 маршрутов (`mod_unit.sv`) |
| `0x3000_0000` | Шина сигналов и выходной микшер (`avk/fx_bus.sv`): `OUT_DC`, `OUT2_DC`, `OUT2_SEL`, `OUT2_GAIN`, `+0x40` усиления `GAIN[i]` шины в ВЫХ, `+0x100` текущие значения `S[i]` |
| `0x3001_0000` | Слоты: слот k по `+k·0x100`: `TYPE_ID`, `SEL_A`, `SEL_B`, `BYPASS`, `MEM_BASE`, `MEM_SIZE`, `PARAM[0..15]` |
| `0x4000_0000` | Окно внешней памяти (32-битные слова, общая со слотами задержек; `mem/mem_arb.sv`, ожидание подтверждения) |

### 8.3 Хранение прошивки CPU

- Загрузчик (1–2 КБ) — в BSRAM, инициализируется из битстрима.
- Рабочая прошивка — в SPI-флеше Tang Nano по отдельному смещению; загрузчик копирует её в BSRAM.
- Режим разработки: загрузка прошивки по UART (BL702) без пересборки битстрима.
- SD-карта: пресеты; опционально — файл обновления прошивки.

## 9. Разработка и верификация

- Язык: SystemVerilog (синтезируемое подмножество) или Verilog-2005.
- Toolchain для битстримов: **Gowin EDA** (Education edition поддерживает GW1NR-9 и GW2AR-18).
- RTL переносимый: примитивы производителя (PLL, BSRAM, умножители, DDR-выводы SDRAM) — только в тонких обёртках в `boards/`, остальное — обычный RTL с выводом памяти/умножителей синтезатором.
- Открытый маршрут (yosys + nextpnr-himbaechel) — только как второе мнение: сравнить утилизацию и Fmax на этапе 3.
- Модели DSP-блоков на Python (numpy) → эталонные WAV; тесты RTL в Verilator/cocotb со сравнением с эталоном.
- CI (GitHub Actions): линт RTL (Verilator), симуляция, сборка прошивки CPU. Битстрим собирается локально в Gowin EDA.
