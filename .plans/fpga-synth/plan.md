# План реализации: FPGA-синтезатор для АВК-6

ТЗ: [`trs.md`](trs.md). Требования к схеме: [`hw-requirements.md`](hw-requirements.md). Эскиз панели: [`panel-sketch.svg`](panel-sketch.svg).

Принцип: каждый этап заканчивается работающим устройством, которое можно подключить к АВК и послушать.
Этапы 1–6 — на Tang Nano 9K (макет на модулях), с 7-го — на 20K. Параллельно идёт трек «железа» (H1–H4, KiCad; требования к узлам — `hw-requirements.md`, схему и разводку рисует автор проекта).

## Структура репозитория (предложение)

```
fpga/
  rtl/        # SystemVerilog: audio/, voice/, midi/, bus/, slots/, periph/, cpu/
  boards/     # top-level и .cst для tang_nano_9k, tang_nano_20k
  sim/        # тестбенчи Verilator (C++), стимулы MIDI, анализ WAV на Python
  model/      # Python-модели DSP-блоков, генерация эталонных WAV
sw/           # прошивка RISC-V (C): загрузчик, драйверы, меню, распределитель голосов
hw/           # схема и плата (KiCad), чертёж панели
fw/           # существующая прошивка midi2aux (Arduino) — без изменений
```

## Этапы

### Этап 0. Инфраструктура
1. **CI в GitHub Actions — первым делом**, до первой строчки RTL:
   - линт RTL (`verilator --lint-only -Wall`);
   - симуляция в Verilator: тестбенч подаёт на вход поток MIDI-байтов (и сигналы ВХ1/ВХ2 из файлов), снимает выход I2S → WAV;
   - анализ на Python: спектр (частота основного тона против таблицы нот, гармоники, шум), осциллограммы, огибающие; проверки с допусками → pass/fail;
   - графики (PNG) и WAV — артефакты сборки, их можно скачать и послушать;
   - сборка C-прошивки RISC-V (`riscv-none-elf-gcc` / `riscv64-unknown-elf-gcc`).
2. Каркас `fpga/`, `sw/`, `hw/`, скрипты сборки (`make lint`, `make sim`, `make fw`).
3. Проекты Gowin EDA для 9K и 20K (`fpga/boards/`), обёртки примитивов (PLL, BSRAM). Битстрим собирается локально.
4. Python-модели: NCO, ADSR, SVF → эталонные WAV для сравнения с RTL.
- **Готово, когда:** CI зелёный на заглушечном модуле (генератор синуса → I2S → WAV → проверка частоты), «мигалка» из Gowin EDA работает на 9K.
- **Статус:** сделано всё, кроме проверки на железе: CI (`.github/workflows/fpga-synth.yml`), `make lint/sim/model/fw/test`,
  `stub_core` (синус + пила → I2S, эхо MIDI, мигалка), модели NCO/ADSR/SVF, скрипты `gw_sh` для 9K и 20K.
  Осталось у автора: собрать битстрим в Gowin EDA и проверить «мигалку» на 9K. См. `fpga/README.md`.
- **Решения этапа 0:**
  - sys_clk = 99 МГц (rPLL 27 · 11 / 3), BCK = sys_clk / 32, fs = 48 339.84 Гц (+0.7 %);
  - таблица синуса — четверть периода, 1024 × 17 бит, без интерполяции (THD+N ≈ −67 дБ); генерируется из модели
    в виде `case`-ROM (`make luts`), а не `$readmemh` — нет зависимости от путей в Verilator/Gowin/yosys;
  - стимулы MIDI — текст `<время_мс> <байты hex>`; входы ВХ1/ВХ2 из файлов подключаются в тестбенч вместе
    с моделью АЦП (этап 6);
  - распиновка I2S/MIDI на макете — предварительная (HO-01): 9K и 20K — выводы 25–29.

### Этап 1. Звук наружу (паритет с midi2aux)
- PLL, `audio_tick` ≈ 48 кГц, I2S TX → модуль PCM5102A.
- UART RX 31250 + парсер MIDI (running status) → FIFO событий.
- Временно: один голос, меандр, реакция на последнюю ноту — прямо в RTL.
- Выходной каскад на макетке: ОУ ±15 В → ±10 В. Проверить DC-тракт PCM5102A (O-09).
- **Готово, когда:** клавиатура играет одноголосно через АВК, как старый midi2aux.

### Этап 2. Процессор
- PicoRV32 + BSRAM + шина + UART-отладка + таймер.
- Загрузчик: прошивка по UART (BL702) и из SPI-флеша.
- MIDI FIFO читается CPU; `printf` событий в UART.
- **Готово, когда:** C-прошивка обновляется за секунды без пересборки битстрима и печатает ноты.

### Этап 3. Полифония
- Голосовой движок с мультиплексированием по времени, параметр `NUM_VOICES`.
- 2 NCO на голос (пила, меандр/PWM, треугольник, синус), шум, смесь, расстройка.
- ADSR1 → громкость; velocity → громкость.
- Сумматор с запасом разрядности + софт-лимитер.
- Распределитель голосов на C: свободный голос / кража; pitch bend, mod wheel.
- Замер ресурсов 9K: сколько голосов влезает. Сравнение Gowin EDA и yosys+nextpnr по LUT и Fmax.
- **Готово, когда:** аккорды и Rush E на 16+ голосах без щелчков и переполнений.

### Этап 4. Тембр
- SVF (ФНЧ/ПФ/ФВЧ, резонанс), ADSR2 → срез, velocity → срез.
- 2 LFO, вибрато от mod wheel.
- Сверка RTL с Python-моделью по WAV.
- **Готово, когда:** звучат классические пэды, басы и «квакающий» фильтр.

### Этап 5. Панель управления
- SPI-контроллер + MCP3208: 8 потенциометров → параметры (сглаживание, гистерезис).
- Декодеры энкодеров, драйвер ST7789, шрифт с кириллицей.
- Каркас меню, построенный из дескрипторов параметров.
- **Готово, когда:** звук настраивается без компьютера.

### Этап 6. Связь с АВК (ключевой этап)
- АЦП входов (2× SAR, 192 кГц → децимация 48 кГц), нормировка ±10 В ↔ ±1.0.
- Вход СИНХР: измерение периода, фронт → триггер нот, такт для LFO.
- Шина сигналов, выходной микшер, ВЫХ2 (второй канал ЦАП).
- Матрица модуляции: ВХ1/ВХ2 → высота / срез / громкость.
- Вывод LFO / огибающей / gate на ВЫХ2 — модуляция АВК от синта.
- Интерфейс слота + слот MATH (A·B, A/B, |A|, …) — проверка архитектуры слотов.
- **Готово, когда:** генератор АВК модулирует фильтр синта, огибающая синта управляет блоком АВК, слот MATH повторяет умножитель АВК.

### Этап 7. Переход на Tang Nano 20K + память
- Top-level и распиновка 20K; контроллер SDRAM + арбитр портов слотов.
- (На 9K допустимо отладить то же на встроенной PSRAM — интерфейс памяти абстрактный.)
- Слот DELAY: обратная связь, dry/wet, время от энкодера и от СИНХР.
- Масштабирование до 32 голосов.
- **Готово, когда:** 32 голоса + 2 задержки, раздельно на ВХ1 и ВХ2, смешиваются на выходе.

### Этап 8. Эффекты P1
- CHORUS/FLANGER, REVERB.
- PolyBLEP, жёсткая синхронизация от СИНХР, sustain, остальная матрица модуляции, envelope follower, pitch CV на ВЫХ2.

### Этап 9. Пресеты и сервис
- FAT на SD: сохранение и загрузка пресетов (синт + маршрутизация + слоты).
- Прошивка CPU во флеш из файла на SD.

### Этап 10. Интеграция
- Калибровка ВХ/ВЫХ (смещение, масштаб), проверка при Volume = max.
- Демонстрационные схемы набора на АВК (для статьи).

## Трек «железо»

| # | Шаг | Когда |
|---|---|---|
| H1 | Макет на модулях: PCM5102A, MCP3208, 2 АЦП SAR, ОУ, оптрон, ST7789, энкодеры | к этапам 1–6 |
| H2 | Схема несущей платы в KiCad по `hw-requirements.md`: питание, входы/выходы, АЦП/ЦАП, MIDI, СИНХР, LED перегрузки, органы управления, Tang Nano | можно начинать сразу; назначение пинов ПЛИС фиксируется после этапа 6 |

## Оценка ресурсов (грубо, уточнить синтезом)

| Блок | LUT | Умножители 18×18 | BSRAM |
|---|---|---|---|
| PicoRV32 + периферия | ~2.5K | 0–4 | 2–3 блока + код |
| Голосовой движок (32 голоса) | ~2–3K | 4–6 | 2–4 |
| SVF, огибающие, LFO | внутри движка | | |
| Слот MATH | ~0.5K | 1–2 | — |
| Слот DELAY + контроллер SDRAM | ~1K | 1 | 1 |
| REVERB | ~1K | 2 | 4–8 (или SDRAM) |
| **Итого** | **~8K** | **~15** | **~20** |

9K (8.6K LUT, 20 умножителей, 26 BSRAM): этапы 1–6 с запасом по голосам 16–32.
20K (20.7K LUT, 48 умножителей, 46 BSRAM): полная конфигурация с запасом ~2×.
