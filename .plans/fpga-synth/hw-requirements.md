# Требования к схеме и плате: FPGA-синтезатор АВК-6

Статус: **черновик v0.1**. Сопутствующие документы: [`trs.md`](trs.md) (ТЗ), [`panel-sketch.svg`](panel-sketch.svg) (панель).
Схема и плата делаются в **KiCad**. Документ задаёт требования (`Т-xx`) и рекомендуемую реализацию с расчётом номиналов. Рекомендованные компоненты можно заменить, если требования выполняются.

Открытые вопросы — в разделе 16 (`HO-xx`).

---

## 0. Общая структура

```
                      Нижний разъём модуля (+5, ±15, ⊥, СИНХР)
                                   │
   ┌───────────────────────────────┼─────────────────────────────────────────────┐
   │  Питание: +5 → Tang Nano (через Шоттки), LDO 3.3A (аналог), LDO 3.3D (цифра) │
   │           ±15 → ОУ, компараторы; REF 2.5 В (опора АЦП и смещения)           │
   └──────────────────────────────────────────────────────────────────────────────┘
 ВХ1 ─ делитель+смещение ─ ФНЧ ─ буфер RRIO ─ АЦП1 ─┐
 ВХ2 ─ делитель+смещение ─ ФНЧ ─ буфер RRIO ─ АЦП2 ─┤ SPI
 8 потенциометров ─ RC ─ MCP3208 ───────────────────┤ SPI
 MIDI TRS ─ мост ─ оптрон ──────────────────────────┤             ┌───────────────┐
 СИНХР ─ R + ограничитель ─ триггер Шмитта ─────────┼─────────────┤ Tang Nano 20K │
 4 энкодера ─ подтяжки + RC ────────────────────────┤             │  (на гребёнках)│
 Дисплей ST7789 (SPI) + подсветка (MOSFET) ─────────┘             └──────┬────────┘
                                                                         │ I2S + XSMT
                                   PCM5102A ─ L ─ ГРОМКОСТЬ ─ ОУ ×4.2 ─ ВЫХ ─┬─ LM339 ─ LED +10/−10
                                             └ R ────────────── ОУ ×4.2 ─ ВЫХ2
```

## 1. Сигнальные уровни и шкалы (общие для всех узлов)

| # | Требование |
|---|---|
| Т-1.1 | Машинная единица АВК: ±10 В. |
| Т-1.2 | Полная шкала (FS) аналоговых входов и выходов: **±12.5 В**; ±10 В = 0.8 FS. Запас 25 % нужен, чтобы видеть перегрузки АВК и не резать сигнал на ровно ±10 В. |
| Т-1.3 | Входы и выходы связаны по постоянному току (без разделительных конденсаторов). |
| Т-1.4 | Логика ПЛИС — LVCMOS 3.3 В. Ни один сигнал к ПЛИС не превышает 3.3 В ни при каком состоянии питания. |

## 2. Питание

| # | Требование |
|---|---|
| Т-2.1 | Источники — только от нижнего разъёма модуля: +5 В, +15 В, −15 В, ⊥. Единая земля АВК. |
| Т-2.2 | Tang Nano питается через свой вывод 5 В на гребёнке, через диод Шоттки (≥1 А, Vf ≤ 0.4 В, напр. SS14 / B130). Диод исключает обратное питание АВК от USB при прошивке на проставке. |
| Т-2.3 | Отдельный LDO **3.3A** (аналог): PCM5102A AVDD/CPVDD, АЦП входов, буферы входов, MCP3208 и питание потенциометров. Шумы ≤ 10 мкВ rms (LP5907-3.3, TPS7A2033 или аналог), ток ≥ 150 мА. |
| Т-2.4 | Отдельный LDO **3.3D** (цифра): DVDD PCM5102A, логика VDRIVE АЦП, дисплей, подтяжки энкодеров, оптрон, триггер Шмитта. Ток ≥ 300 мА (AP2112K-3.3, AMS1117-3.3). |
| Т-2.5 | Потребители 3.3D не должны питать ПЛИС через выводы I/O, когда ПЛИС обесточена. Т.к. всё питается от одного +5 В, достаточно одновременного включения; последовательные резисторы 33–100 Ом в линиях, идущих в ПЛИС. |
| Т-2.6 | Опорное напряжение **REF 2.5 В**, ≤ 20 ppm/°C, ≤ 0.1 % (REF3025, ADR361, LM4040C25 с буфером). Используется как REFIN обоих АЦП входов и как источник смещения входных каскадов (ратиометрическая схема). |
| Т-2.7 | ±15 В — на ОУ входов/выходов и компараторы. Фильтр на входе каждой шины: ферритовая бусина + 10 мкФ + 100 нФ. |
| Т-2.8 | Развязка: 100 нФ у каждого вывода питания каждой микросхемы; 10 мкФ на каждую шину у группы. Электролит 47–100 мкФ на +5, +15, −15 на входе платы (у АВК слабые фильтры — см. статью, помехи >1 В). |
| Т-2.9 | Защита от переполюсовки не требуется (разъём с ключом), но на ±15 В — диоды Шоттки от шины к земле в обратном направлении (защита ОУ при несимметричном включении). |
| Т-2.10 | Бюджет тока (оценка): +5 В ≤ 400 мА (Tang Nano 20K ~200 мА, подсветка ~30 мА, LDO 3.3A/3.3D ~80 мА); +15 / −15 В ≤ 30 мА каждая. |
| Т-2.11 | Контрольные точки на каждой шине: +5, +15, −15, 3.3A, 3.3D, REF2.5, ⊥ (несколько). |

## 4. MIDI-вход (TRS 3.5 мм)

| # | Требование |
|---|---|
| Т-4.1 | Соответствие MIDI 1.0 (токовая петля 5 мА, 31.25 кбод) и MMA RP-054 **TRS Type A**: Tip = MIDI pin 5 (sink), Ring = pin 4 (source), Sleeve = pin 2 (экран, не соединять с землёй на приёмнике). Сверить с RP-054 при разводке. |
| Т-4.2 | Работа с кабелями **Type A и Type B** без переделки: диодный мост из Шоттки (2× BAT54S) перед светодиодом оптрона. |
| Т-4.3 | Гальваническая развязка: оптрон с выходом ≤ 2 мкс по фронтам, питание 3.3 В: **H11L1** (с триггером Шмитта) или 6N137 / TLP2361 (3.3 В версия). Порог срабатывания светодиода ≤ 2 мА. |
| Т-4.4 | Последовательный резистор 220 Ом (для моста — 180 Ом с учётом падения на Шоттки), защитный диод 1N4148 встречно светодиоду (при мосте не нужен). |
| Т-4.5 | Выход оптрона — открытый коллектор, подтяжка 1–2.2 кОм к 3.3D, в ПЛИС. |
| Т-4.6 | Гнездо — 3.5 мм стерео, крепление на панель гайкой (PJ-392 / Lumberg 1503) или на плату с выходом втулки через отверстие панели. |

| # | Требование |
|---|---|
| Т-5.1 | Уровень сигнала предположительно ТТЛ 0/+5 В (HO-02). Вход должен корректно работать с: ТТЛ; ±5 В; ±10 В; выдерживать ±15 В неограниченно долго. |
| Т-5.2 | Входное сопротивление ≥ 20 кОм. |
| Т-5.3 | Порог ≈ +1.4 В, гистерезис ≥ 0.4 В; частота до 1.1 кГц (с запасом — до 20 кГц); фронт на выходе ≤ 100 нс. |
| Т-5.4 | Реализация: 22 кОм последовательно → Шоттки-ограничитель BAT54S на 3.3D/⊥ → 100 пФ на ⊥ → **74LVC1G17** (триггер Шмитта, 3.3 В) → ПЛИС. Ток через ограничитель при 15 В ≈ 0.5 мА — шина 3.3D должна его поглощать (нагрузка на шине заведомо больше). |
| Т-5.5 | Контрольная точка до и после триггера. |

## 6. Аналоговые входы ВХ1, ВХ2

| # | Требование |
|---|---|
| Т-6.1 | Диапазон ±12.5 В → 0…2.5 В на входе АЦП (Vadc = 1.25 + 0.1·Vin). Неинвертирующая схема (знак сохраняется). |
| Т-6.2 | Входное сопротивление ≥ 100 кОм. Выдерживает ±15 В неограниченно долго без повреждения и без выхода напряжения на АЦП за 0…VDD. |
| Т-6.3 | ФНЧ-антиалиасинг **2-го порядка**, Баттерворт, fc = 20 кГц ±10 %; ослабление на 172 кГц (fs_ADC − 20 кГц при fs_ADC = 192 кГц) ≥ 35 дБ. |
| Т-6.4 | Погрешность до калибровки: смещение ≤ 50 мВ (приведено ко входу), усиление ≤ 1 %. После программной калибровки: ≤ 10 мВ и ≤ 0.2 %. Дрейф ≤ 1 мВ/°C. |
| Т-6.5 | Шум, приведённый ко входу, ≤ 1 мВ rms в полосе 20 кГц (≈ 12-битный АЦП не должен упираться в шум каскада). |
| Т-6.6 | Идентичность каналов (для операций A·B, A/B): задержка между каналами ≤ 1 мкс (одинаковые фильтры, одновременная выборка АЦП). |

**Рекомендуемая реализация (на каждый канал):**

1. Пассивный сумматор на неинвертирующем входе: `Vin —Ra— узел —Rb— REF2.5`, `узел —Rc— ⊥`.
   Условия: вес Vin = 0.1, вес REF = 0.5 → `1/Ra : 1/Rb : 1/Rc = 0.1 : 0.5 : 0.4`.
   **Ra = 100 кОм, Rb = 20.0 кОм, Rc = 24.9 кОм** (0.1 %). Rвх ≈ Ra + Rb‖Rc ≈ 111 кОм; Rвых узла = 10 кОм.
2. Ограничитель в узле: BAT54S на 3.3A и ⊥. При Vin = ±15 В узел = −0.25…+2.75 В — ограничитель срабатывает только на −15 В, ток ≤ 0.15 мА.
3. ФНЧ Саллена–Ки 2-го порядка на ОУ с однополярным питанием 3.3A, **RRIO**, малошумящий, Vos ≤ 1 мВ: OPA2350, OPA2365, MCP6022, TLV9062 (одна сдвоенная микросхема на оба канала). Выходное сопротивление узла (10 кОм) входит в первый резистор фильтра. Выход ОУ сам ограничен рельсами 0…3.3 В.
4. На входе АЦП: 33–49.9 Ом последовательно + 1–2.2 нФ C0G на ⊥ (по рекомендации даташита АЦП к «заряду» входа).

## 7. АЦП входов

| # | Требование |
|---|---|
| Т-7.1 | 2 независимых канала, **одновременная выборка** (общий CONVST/CS). |
| Т-7.2 | Разрешение ≥ 12 бит, скорость ≥ 200 кSPS на канал (работаем на 192 кSPS → децимация 4:1 в ПЛИС). |
| Т-7.3 | Внешний опорный вход 2.5 В (общий REF, Т-2.6) — ратиометрично со смещением входного каскада. |
| Т-7.4 | Отдельное питание логики (VDRIVE/VIO) 3.3 В, SPI ≥ 16 МГц. |
| Т-7.5 | Рекомендуется **AD7091R** (12 бит, 1 MSPS, REFIN/REFOUT, VDRIVE) ×2. Альтернатива: ADS7042 (опора = AVDD → питать от REF3025 не рекомендуется), AD7988-5 (16 бит, если захочется больше). |

## 8. ЦАП

| # | Требование |
|---|---|
| Т-8.1 | **PCM5102A**, режим I2S (FMT = 0), внутренний PLL от BCK (SCK на ⊥), BCK = 64·fs. |
| Т-8.2 | Фильтр: FLT = 1 (low latency) — минимальная задержка важна при обработке сигналов АВК. DEMP = 0. |
| Т-8.3 | XSMT управляется ПЛИС (подтяжка 10 кОм к ⊥ → при старте ЦАП молчит, пока ПЛИС не разрешит). |
| Т-8.4 | Питание: AVDD и CPVDD — 3.3A; DVDD — 3.3D; LDOO и конденсаторы накачки — строго по даташиту (2.2 мкФ, 1 мкФ X7R). |
| Т-8.5 | Проверить на макете (HO-03): тракт пропускает постоянную составляющую; смещение на выходе ≤ 5 мВ; поведение при автоматическом mute на нулевых данных. |
| Т-8.6 | Выход ЦАП: ±2.97 В пик (2.1 В rms) = FS. Нагрузка ЦАП ≥ 1 кОм. |

## 9. Выходы ВЫХ, ВЫХ2

| # | Требование |
|---|---|
| Т-9.1 | Полная шкала ЦАП → ±12.5 В: усиление **×4.21**. ±10 В при 0.8 FS. |
| Т-9.2 | ВЫХ: ЦАП L → потенциометр ГРОМКОСТЬ (делитель) → неинвертирующий усилитель. В крайнем положении ГРОМКОСТЬ передача точно ×1 (движок = верхний вывод). |
| Т-9.3 | ВЫХ2: ЦАП R → неинвертирующий усилитель ×4.21, без регулятора. |
| Т-9.4 | Нагрузка ≥ 2 кОм при ±12.5 В; устойчивость на ёмкость кабеля до 1 нФ; устойчивость к КЗ на ⊥ неограниченно долго. |
| Т-9.5 | Выходное сопротивление ≤ 1 Ом на НЧ (резистор защиты внутри петли ОС). |
| Т-9.6 | Сглаживающий ФНЧ: 1-й порядок, fc ≈ 40–50 кГц (конденсатор параллельно Rf). |
| Т-9.7 | Смещение нуля ≤ 20 мВ до калибровки, шум ≤ 200 мкВ rms (20 кГц). |
| Т-9.8 | При подаче/снятии питания на выходе нет выбросов более ±12.5 В; ЦАП заглушен XSMT до готовности ПЛИС. |

**Рекомендуемая реализация:**

- ОУ: **OPA2171** (±18 В, rail-to-rail выход, FET-вход — нужен из-за высокого сопротивления движка потенциометра) или OPA2277 / TL072 (выход только до ±12.5 В с малым запасом — хуже).
- Усиление: Rf = 32.4 кОм, Rg = 10.0 кОм (0.1 %) → ×4.24; точная подстройка программно. Cf = 100 пФ → fc ≈ 49 кГц.
- Защита: 100 Ом последовательно в выходе, ОС снимается после резистора; 47 пФ с выхода ОУ на инвертирующий вход для устойчивости.
- ГРОМКОСТЬ: 10 кОм, логарифмический (A) или линейный с «логарифмирующим» резистором (HO-04), 16 мм / 9 мм с крупной ручкой. Верх — ЦАП L, низ — ⊥, движок — неинвертирующий вход ОУ через 1 кОм.

## 10. Индикация перегрузки ВЫХ (+10 / −10)

| # | Требование |
|---|---|
| Т-10.1 | Индицирует напряжение **на штыре ВЫХ** (после ГРОМКОСТИ): «+10» при V > +10 В, «−10» при V < −10 В. Порог ±10 В ±0.3 В. |
| Т-10.2 | Растяжка импульса: светодиод горит ≥ 50 мс после короткого превышения (видно одиночные пики). |
| Т-10.3 | Не нагружает выход (Rвх ≥ 100 кОм). |
| Т-10.4 | Реализация: **LM339** от ±15 В: 2 компаратора — детекторы, 2 — растяжители (диод + RC 100 кОм / 1 мкФ). Пороги — делители от ±15 В или от REF2.5 через масштабирование. Светодиоды: анод через резистор к ⊥, катод к выходу компаратора (открытый коллектор тянет к −15 В); 6.8 кОм → ≈ 1.9 мА (светодиоды повышенной яркости, 3 мм, красные). Можно взять схему индикации из модуля умножителя AD633. |

## 15. Плата

| # | Требование |
|---|---|
| Т-15.1 | Габарит — не больше 120×90 мм минус зоны направляющих АВК; крепёжные отверстия под стойки в тех же координатах, что и на панели (4 мм от углов). |
| Т-15.2 | **4 слоя** (сигнал / сплошная ⊥ / питание / сигнал) — рекомендуется. При 2 слоях — сплошной полигон ⊥ снизу, без разрезов под аналоговой частью. |
| Т-15.3 | Зонирование: аналоговые узлы (входы, АЦП, ЦАП, выходные ОУ, REF) — в одной зоне, дальше от Tang Nano и SDRAM; цифровые линии не проходят под аналоговыми узлами. |
| Т-15.4 | Все элементы панели (потенциометры, энкодеры, гнездо MIDI, светодиоды, дисплей) стоят на несущей плате и выходят в отверстия панели; высота стоек подбирается под длину валов (HO-05). |
| Т-15.5 | Отладочные точки: I2S (BCK, LRCK, DIN), MIDI после оптрона, СИНХР после триггера, SPI АЦП, аналоговые узлы ВХ1/ВХ2 на входе АЦП, выходы ЦАП L/R. |
| Т-15.6 | Шелкография: подписи всех разъёмов, полярность, версия платы. |
| Т-15.7 | Компоненты — по возможности SMD 0603/0805, SOIC/SOT-23 (ручная пайка), кроме панельных. |
